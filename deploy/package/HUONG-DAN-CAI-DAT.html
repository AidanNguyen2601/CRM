1. Tổng quan

Gói cài đặt CRM là một thư mục (hoặc file crm-<phiên bản>.zip) gồm:

Thành phầnMô tả
images\crm-web.tarỨng dụng CRM đã biên dịch (đóng gói dạng Docker image)
images\sqlserver.tarMicrosoft SQL Server 2022 (có thể không có nếu gói được tạo bản “nhẹ” – khi đó máy đích cần Internet)
install.ps1 / install.shScript cài đặt cho Windows / Linux
backup.ps1, restore.ps1Sao lưu / khôi phục database và file đính kèm
uninstall.ps1Gỡ cài đặt
docker-compose.yml, VERSIONCấu hình chạy và số phiên bản (không cần sửa)

Sau khi cài, CRM chạy thành 2 thành phần độc lập trên máy đích: web (giao diện CRM) và db (SQL Server). Dữ liệu được lưu bền vững trong Docker volume, không mất khi khởi động lại máy hay nâng cấp.

2. Yêu cầu máy đích

Hạng mụcTối thiểuKhuyến nghị
Hệ điều hànhWindows 10/11 (64-bit, bản Pro/Enterprise/Home đều được)Windows 11 Pro hoặc Ubuntu Server 22.04/24.04
CPU2 nhân, hỗ trợ ảo hoá (VT-x / AMD-V)4 nhân
RAM4 GB8 GB trở lên (SQL Server dùng khoảng 2 GB)
Ổ đĩa trống6 GB20 GB trở lên (dữ liệu + file đính kèm + bản sao lưu)
MạngKhông cần Internet nếu gói có đủ 2 file trong images\. Cần mở 1 cổng web (mặc định 8100) nếu cho máy khác truy cập.
QuyềnTài khoản Windows có quyền Administrator để cài Docker Desktop
Windows Server: Docker Desktop không hỗ trợ chính thức trên Windows Server. Nếu máy đích là máy chủ, nên dùng một máy ảo / máy chủ Linux (xem mục 13) hoặc Windows 10/11.
Bản quyền: Docker Desktop miễn phí cho cá nhân và doanh nghiệp nhỏ (dưới 250 nhân viên và doanh thu dưới 10 triệu USD/năm); doanh nghiệp lớn hơn cần mua gói Docker. Docker Engine trên Linux miễn phí. SQL Server mặc định ở bản Developer (dùng cho thử nghiệm / demo); khi dùng thật nên chuyển sang Express (miễn phí, tối đa 10 GB mỗi database) – xem mục 7.

3. Cài Docker (chỉ làm một lần)

1
Tải Docker Desktop for Windows tại https://www.docker.com/products/docker-desktop/ (nếu máy đích không có Internet, tải trên máy khác rồi chép file Docker Desktop Installer.exe sang).
2
Chạy file cài đặt, giữ tuỳ chọn Use WSL 2 (mặc định). Cài xong khởi động lại máy nếu được yêu cầu.
3
Mở Docker Desktop, chấp nhận điều khoản, đợi biểu tượng cá voi ở khay hệ thống chuyển sang trạng thái Engine running (màu xanh).
4
Vào Settings → General, bật Start Docker Desktop when you sign in để CRM tự chạy sau khi khởi động lại máy.
5
Kiểm tra: mở PowerShell và chạy 
docker version
docker compose version
Cả hai lệnh đều in ra số phiên bản là đạt.
Nếu báo lỗi WSL hoặc ảo hoá: chạy PowerShell bằng quyền Administrator lệnh wsl --install rồi khởi động lại; và bật Virtualization (VT-x / SVM) trong BIOS nếu đang tắt.

4. Cài đặt CRM

1
Chép file crm-<phiên bản>.zip sang máy đích và giải nén vào một thư mục cố định, ví dụ C:\CRM. Không đặt trong thư mục Downloads / Desktop tạm, vì sau này sao lưu và nâng cấp đều chạy từ thư mục này.
2
Mở thư mục C:\CRM\crm-<phiên bản>, bấm vào thanh địa chỉ, gõ powershell rồi Enter để mở PowerShell ngay tại thư mục đó.
3
Chạy lệnh cài đặt: 
powershell -ExecutionPolicy Bypass -File .\install.ps1
Tuỳ chọn thêm (không bắt buộc):
Tham sốÝ nghĩaVí dụ
-PortCổng web. Mặc định tự chọn cổng trống bắt đầu từ 8100-Port 8080
-SampleCustomersSố khách hàng mẫu khi tạo database lần đầu (mặc định 5; 0 = bộ mẫu chuẩn 8 khách hàng)-SampleCustomers 5
-SqlEditionPhiên bản SQL Server: Developer (mặc định – thử nghiệm / demo) hoặc Express (miễn phí, dùng thật). Chọn ngay từ lần cài đầu.-SqlEdition Express
-NoBrowserKhông tự mở trình duyệt khi cài xong
4
Script sẽ lần lượt: kiểm tra Docker → tạo file cấu hình .env (tự sinh mật khẩu SQL Server mạnh) → nạp image → khởi động → đợi ứng dụng sẵn sàng. Lần đầu mất khoảng 1–3 phút. Khi thấy dòng 
[OK]  CRM đã chạy: http://localhost:8100
là cài đặt thành công; trình duyệt sẽ tự mở trang đăng nhập.
Database được tạo sẵn kèm dữ liệu mẫu (khách hàng, cơ hội, báo giá, hợp đồng, hoá đơn, thanh toán, chỉ tiêu KPI) để làm quen. Có thể xoá dần hoặc giữ làm ví dụ.

5. Việc cần làm ngay sau khi cài

Tài khoản mẫuMật khẩuVai trò
adminAdmin@123Quản trị hệ thống
managerManager@123Quản lý kinh doanh
sales1, sales2Sales@123Nhân viên kinh doanh
Bắt buộc: đăng nhập admin → menu tài khoản (góc phải) → Đổi mật khẩu. Sau đó vào Hệ thống → Người dùng & phân quyền để đổi mật khẩu / khoá các tài khoản mẫu và tạo tài khoản thật cho nhân viên.
  • Kiểm tra / bổ sung danh mục: Danh mục → hàng hoá, ngành nghề, tỉnh thành, đơn vị tính, phương thức thanh toán…
  • Giao chỉ tiêu KPI: Tổng quan → KPI bán hàng → Giao chỉ tiêu.
  • Đặt lịch sao lưu tự động (mục 8).
  • Cất giữ file .env ở nơi an toàn (chứa mật khẩu SQL Server).

6. Cho máy khác trong mạng truy cập

Người dùng truy cập bằng địa chỉ http://<IP-máy-cài>:<cổng>, ví dụ http://192.168.1.20:8100. Xem IP của máy cài bằng lệnh ipconfig (dòng IPv4 Address).

Mở cổng trên Windows Firewall (PowerShell quyền Administrator, đổi 8100 nếu dùng cổng khác):

New-NetFirewallRule -DisplayName "CRM web 8100" -Direction Inbound -Protocol TCP -LocalPort 8100 -Action Allow
Đưa ra Internet: CRM chạy giao thức HTTP. Nếu cần truy cập từ ngoài công ty, hãy đặt phía trước một reverse proxy có HTTPS (IIS + URL Rewrite, Nginx hoặc Caddy) hoặc dùng VPN. Không mở trực tiếp cổng CRM ra Internet.

7. Cấu hình (file .env)

File .env nằm trong thư mục cài đặt, được tạo ở lần cài đầu tiên. Sửa bằng Notepad, sau đó chạy docker compose up -d trong thư mục đó để áp dụng.

BiếnÝ nghĩa
CRM_WEB_PORTCổng web
CRM_SA_PASSWORDMật khẩu tài khoản sa của SQL Server. Không đổi sau khi đã cài (SQL Server chỉ nhận mật khẩu này lúc tạo lần đầu).
CRM_SAMPLE_CUSTOMERSSố khách hàng mẫu – chỉ có tác dụng khi database còn trống (lần cài đầu)
CRM_SQL_EDITIONDeveloper (thử nghiệm / demo) hoặc Express (miễn phí, dùng thật, tối đa 10 GB mỗi database). Chỉ có hiệu lực khi SQL Server được tạo lần đầu – xem ghi chú bên dưới.
CRM_VERSIONPhiên bản đang chạy – script cài đặt tự cập nhật, không sửa tay
Đổi Developer → Express sau khi đã cài: (1) backup.ps1 → (2) uninstall.ps1 -RemoveData → (3) xoá file .env → (4) install.ps1 -SqlEdition Express → (5) restore.ps1 .\backups\<bản vừa sao lưu>. Bản Express chỉ dùng tối đa ~1,4 GB RAM và 10 GB mỗi database – đủ cho phần lớn doanh nghiệp vừa và nhỏ.

8. Sao lưu & khôi phục

Sao lưu thủ công

cd C:\CRM\crm-<phiên bản>
powershell -ExecutionPolicy Bypass -File .\backup.ps1

Kết quả nằm trong backups\<ngày-giờ>\ gồm CRM_DB.bak (database) và files.tgz (file đính kèm). Hãy chép thư mục backups sang ổ khác / máy khác / lưu trữ đám mây.

Đặt lịch sao lưu hằng ngày (2 giờ sáng)

PowerShell quyền Administrator (sửa đường dẫn cho đúng thư mục cài):

$dir = "C:\CRM\crm-<phiên bản>"
$act = New-ScheduledTaskAction -Execute "powershell.exe" -Argument "-ExecutionPolicy Bypass -File `"$dir\backup.ps1`"" -WorkingDirectory $dir
$trg = New-ScheduledTaskTrigger -Daily -At 2am
Register-ScheduledTask -TaskName "CRM backup" -Action $act -Trigger $trg -RunLevel Highest -User $env:USERNAME
Docker Desktop chỉ chạy khi người dùng đã đăng nhập Windows. Máy cài CRM nên để đăng nhập sẵn (khoá màn hình thay vì đăng xuất). Nhớ định kỳ xoá bớt các bản sao lưu cũ.

Khôi phục

powershell -ExecutionPolicy Bypass -File .\restore.ps1 .\backups\20261113-020000

Script hỏi xác nhận (gõ YES), sau đó ghi đè toàn bộ dữ liệu hiện tại bằng bản sao lưu đã chọn.

9. Chuyển dữ liệu từ máy CRM cũ sang (tuỳ chọn)

Bỏ qua mục này nếu chỉ cần dữ liệu mẫu. Nếu muốn mang toàn bộ dữ liệu thật đang có:

a) Máy cũ cũng cài bằng gói này

Chạy backup.ps1 trên máy cũ → chép thư mục backups\<ngày-giờ> sang máy mới → chạy restore.ps1 <thư mục đó> trên máy mới.

b) Máy cũ là máy phát triển (CRM dùng chung SQL Server với ứng dụng khác)

Trên máy cũ, tại thư mục mã nguồn CRM (có file .env), chạy PowerShell:

$dbPass = (Select-String '^SHARED_DB_PASSWORD=(.*)' .\.env).Matches[0].Groups[1].Value
$sql = (Select-String '^SHARED_DB_HOST=(.*)' .\.env).Matches[0].Groups[1].Value
New-Item -ItemType Directory -Force .\chuyen-du-lieu | Out-Null

# Database
docker exec $sql /opt/mssql-tools18/bin/sqlcmd -C -S localhost -U crm_app -P $dbPass -Q "BACKUP DATABASE CRM_DB TO DISK='/tmp/CRM_DB.bak' WITH INIT"
docker cp "${sql}:/tmp/CRM_DB.bak" .\chuyen-du-lieu\CRM_DB.bak

# File đính kèm
docker exec crm-web tar czf /tmp/files.tgz -C /app/uploads .
docker cp crm-web:/tmp/files.tgz .\chuyen-du-lieu\files.tgz

Chép thư mục chuyen-du-lieu sang máy mới (ví dụ vào C:\CRM\crm-<phiên bản>\chuyen-du-lieu) rồi chạy:

powershell -ExecutionPolicy Bypass -File .\restore.ps1 .\chuyen-du-lieu
Sau khi khôi phục, tài khoản và mật khẩu người dùng là của hệ thống cũ. Người dùng sẽ phải đăng nhập lại.

10. Nâng cấp phiên bản mới

1
Chạy backup.ps1 trên bản đang dùng.
2
Giải nén gói mới, chép toàn bộ file của gói mới đè lên thư mục cài đặt hiện tại. Giữ nguyên file .env và thư mục backups.
3
Chạy lại install.ps1. Script nhận ra cấu hình cũ, chỉ nạp phiên bản mới và khởi động lại. Dữ liệu được giữ nguyên; cấu trúc database tự nâng cấp khi ứng dụng khởi động.

11. Gỡ cài đặt

LệnhKết quả
.\uninstall.ps1Dừng và gỡ CRM, giữ dữ liệu (cài lại sẽ thấy dữ liệu cũ)
.\uninstall.ps1 -RemoveDataGỡ và xoá vĩnh viễn database + file đính kèm (hỏi xác nhận). Nên chạy backup.ps1 trước.

12. Xử lý sự cố

Các lệnh chạy trong thư mục cài đặt:

docker compose ps               # trạng thái: db, web phải là "running" / "healthy"
docker compose logs --tail 100 web   # xem log ứng dụng
docker compose restart web      # khởi động lại ứng dụng
docker compose up -d            # khởi động lại toàn bộ (sau khi sửa .env, sau khi khởi động lại máy)
Hiện tượngNguyên nhân / cách xử lý
Docker chưa chạy khi càiMở Docker Desktop, đợi trạng thái Engine running rồi chạy lại install.ps1.
…cannot be loaded because running scripts is disabledLuôn chạy bằng powershell -ExecutionPolicy Bypass -File .\install.ps1 (không double-click file .ps1).
Trình duyệt báo không truy cập được trang sau khi khởi động lại máyDocker Desktop chưa chạy hoặc chưa đăng nhập Windows. Mở Docker Desktop; nếu vẫn không được chạy docker compose up -d.
Cài báo Ứng dụng chưa phản hồi sau 6 phútXem log được in ra. Thường do máy thiếu RAM (SQL Server cần ~2 GB): đóng bớt ứng dụng, hoặc tăng bộ nhớ cho Docker trong Settings → Resources. Sau đó chạy lại install.ps1.
port is already allocatedCổng đã bị phần mềm khác dùng. Sửa CRM_WEB_PORT trong .env rồi docker compose up -d.
Máy khác không vào đượcKiểm tra IP đúng chưa, đã mở firewall (mục 6) chưa, hai máy cùng mạng chưa.
Quên mật khẩu adminMột tài khoản quản trị khác vào Người dùng & phân quyền đặt lại. Nếu không còn ai: khôi phục từ bản sao lưu cũ, hoặc liên hệ bộ phận phát triển.
Hết dung lượng ổ đĩaXoá bớt bản sao lưu cũ trong backups; dọn Docker: docker system prune (không xoá dữ liệu CRM).

13. Cài trên Linux (Ubuntu)

# 1. Cài Docker Engine (cần Internet một lần)
curl -fsSL https://get.docker.com | sudo sh
sudo usermod -aG docker $USER      # đăng xuất / đăng nhập lại để có hiệu lực

# 2. Giải nén gói và cài (cổng 8100, 5 khách hàng mẫu)
unzip crm-<phiên bản>.zip -d /opt/crm
cd /opt/crm/crm-<phiên bản>
chmod +x install.sh
./install.sh 8100 5 Express     # cổng, số khách hàng mẫu, phiên bản SQL Server (Developer | Express)

# 3. Mở firewall (nếu dùng ufw)
sudo ufw allow 8100/tcp

Trên Linux, CRM tự chạy lại khi khởi động máy (Docker Engine chạy dưới dạng dịch vụ). Các lệnh sao lưu / khôi phục tương đương:

docker compose exec -T db /opt/mssql-tools18/bin/sqlcmd -C -S localhost -U sa -P "$(grep ^CRM_SA_PASSWORD= .env | cut -d= -f2-)" \
  -Q "BACKUP DATABASE CRM_DB TO DISK='/var/opt/mssql/CRM_DB.bak' WITH INIT"
docker compose cp db:/var/opt/mssql/CRM_DB.bak ./CRM_DB.bak
docker compose exec -T web tar czf /tmp/files.tgz -C /app/uploads . && docker compose cp web:/tmp/files.tgz ./files.tgz

Hoặc cài PowerShell trên Linux (sudo snap install powershell --classic) để dùng trực tiếp backup.ps1 / restore.ps1 với lệnh pwsh ./backup.ps1.

14. Danh sách kiểm tra bàn giao

  • Docker Desktop đã cài, bật Start when you sign in
  • Cài CRM thành công, đăng nhập được bằng trình duyệt trên máy cài
  • Đã đổi mật khẩu admin; đã khoá / đổi mật khẩu các tài khoản mẫu
  • Đã tạo tài khoản cho người dùng thật, phân đúng vai trò
  • Máy khác trong mạng truy cập được (đã mở firewall)
  • Đã chạy backup.ps1 thử thành công và đặt lịch sao lưu hằng ngày
  • File .env và bản sao lưu được cất ở nơi an toàn
  • Đã thử khởi động lại máy: CRM tự chạy lại sau khi đăng nhập
  • (Dùng thật) đã cài với -SqlEdition Express hoặc có bản quyền SQL Server phù hợp
CRM – Hướng dẫn cài đặt. Áp dụng cho gói cài đặt tạo bằng deploy\build-package.ps1. Số phiên bản xem trong file VERSION của gói.
